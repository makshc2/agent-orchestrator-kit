## ADDED Requirements

### Requirement: Skill mirrors are generated blocks

The skill `templates/.agents/skills/agent-orchestration/SKILL.md` SHALL carry the Session Start protocol, the Session Exit protocol and the conductor routing paragraph with its table only as three marker-delimited blocks (`session-start`, `session-exit`, `routing`) generated from `session-handoff.mdc` and `agent-orchestration.mdc`. A block body MUST be byte-identical to its source section.

#### Scenario: Block equals its source

- **WHEN** the three blocks of the kit's `SKILL.md` are compared with the sections `## Session Start`, `## Session Exit` of `session-handoff.mdc` and the conductor paragraph plus table of `agent-orchestration.mdc`
- **THEN** each block body equals its source section, and the Session Exit block contains the sentence that an Amp mode is never a `--model`

#### Scenario: Statements outside the mirrored sections are kept

- **WHEN** the text of the kit's `SKILL.md` outside the three blocks is read
- **THEN** it contains "Write session artifacts only to git-tracked paths (never `/tmp`, never gitignored caches)" and "Closed role MAY have a sentence after `—`; metrics stores the canonical token"

### Requirement: Mirror blocks are regenerated by init, update and sync

`init`, `update` and `sync` SHALL rewrite the blocks of the project's `.agents/skills/agent-orchestration/SKILL.md` from the project's own `.agents/rules/*.mdc` before the skills are copied to IDE directories. Text outside the markers MUST be left unchanged, and a skill without markers or a missing source rule MUST be skipped without an error and with a warning that names `update`.

#### Scenario: Sync repairs a drifted block

- **GIVEN** a project whose `session-handoff.mdc` Session Exit section was edited
- **WHEN** `sync --target all` runs
- **THEN** the `session-exit` block in `.agents/skills/agent-orchestration/SKILL.md` and in `.claude/skills/agent-orchestration/SKILL.md` equals the edited section

#### Scenario: Regeneration is idempotent

- **WHEN** `sync` runs twice without edits
- **THEN** the second run reports no changed block and the file bytes are the same

#### Scenario: A legacy skill without markers is skipped

- **GIVEN** a project whose `SKILL.md` has no mirror markers
- **WHEN** `sync` runs
- **THEN** the skill bytes are unchanged and the output names the skipped blocks and the `update` command

### Requirement: Drift between mirrors and sources fails the test suite

The kit's test suite SHALL fail when `syncInstructionMirrors` in check mode reports drift for `templates/`, and the failure message MUST name the block and the command that regenerates it.

#### Scenario: A source edit without regeneration

- **WHEN** a source section in `templates/.agents/rules/session-handoff.mdc` changes and the skill is not regenerated
- **THEN** `npm test` fails and names the `session-exit` block

### Requirement: Instruction texts do not contradict recorded data

Kit templates and `README.md` MUST NOT tell agents to limit an apply session to a few tasks, MUST NOT time-box `/opsx:quick`, and MUST name Amp modes `low`, `medium`, `high`, `ultra`; the skill and README model hints MUST put review on the same level as propose.

#### Scenario: Removed rules stay removed

- **WHEN** templates and `README.md` are searched for "1–3 tasks", "Max ~3 hours", "All tasks in one apply session" and an Amp-mode hint `rush`, `smart` or `deep`
- **THEN** none is found
